# 基于 StyleGAN2-ADA 与 SeFa 的动漫头像生成与修复平台

## 项目简介
本项目针对生成对抗网络在动漫头像创作中属性控制困难、输出分辨率不高等问题，提出了一套融合 StyleGAN2-ADA 与 SeFa 潜空间解耦算法的解决方案，并集成了 Real-ESRGAN 超分辨率重建与 Gradio 交互式 Web 系统。

## 核心功能
- **高保真生成**：基于 Anime Faces 数据集（清洗后 1 万张 64×64 头像）训练，结合自适应数据增强，通过 FID 指标监控选择最优模型快照。
- **精准发色控制**：引入无监督 SeFa 算法，闭式分解生成器权重提取发色语义方向向量，配合风格混合技术，实现统一发色下的面部多样性。
- **4倍超分辨率重建**：集成 Real-ESRGAN_x4plus_anime_6B 模型，将 64×64 低分辨率图像修复至 256×256 高清。
- **交互式 Web 界面**：基于 Gradio 搭建三列响应式布局，支持参数调节、批量生成、一键修复与历史收藏。

## 技术栈
Python / PyTorch / StyleGAN2-ADA / SeFa / Real-ESRGAN / Gradio
